# NETWORKWALKS-B084J-WK4-SUBMISSION

### Project overview
This the fourth lab assignment for the NetworkWalks' Cybersecurity programme. The goal of the project is to perform a complete penetration testing procedure on the web domain of a medical facility, then document the results in a penetration test report.

Submission consists of the following:
- Penetration testing report
- Screenshots of the results
- Retrieved password-protected PDF documents as a result of the report
- Passwords of the PDF files
### Objectives:
- Gather information on the target
- Identify weaknesses in the domain's architecture
- Retrieve confidential data, placed in there for the purpose of evaluating the 
- Document all the information gathered through the previous objectives in a penetration testing report
